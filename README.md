# Analista-de-Requisitos
Analista de Requisitos - Casos fictícios para estudo e currículo

A ideia é criar casos ficticios, como se eu atuasse no mercado como Analista de Requisitos;
- O profissional faz a conexão entre a empresa e o cliente, identificando a necessidade do cliente e trazendo a solução dentro do app;
- Ferramenta utilizada: excalidraw.
- A ideia é desenhar o modelo de negocio ja indicando a solução.
